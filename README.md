# libbitcoin apt repository

Debian packages of Bitcoin Server (`bs`) and Bitcoin Explorer (`bx`) for amd64
and arm64, built from the signed release builds of
[libbitcoin-server](https://github.com/libbitcoin/libbitcoin-server) and
[libbitcoin-explorer](https://github.com/libbitcoin/libbitcoin-explorer).
The repository is signed with the libbitcoin release key.

## Add the repository

```sh
sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://libbitcoin.info/apt/libbitcoin.asc -o /etc/apt/keyrings/libbitcoin.asc
echo "deb [signed-by=/etc/apt/keyrings/libbitcoin.asc] https://libbitcoin.info/apt stable main" | sudo tee /etc/apt/sources.list.d/libbitcoin.list
sudo apt update
```

## Install

| Package | Installs | Command |
| ------- | -------- | ------- |
| `libbitcoin-server` | Bitcoin Server (`bs`) | `sudo apt install libbitcoin-server` |
| `libbitcoin-explorer` | Bitcoin Explorer (`bx`) | `sudo apt install libbitcoin-explorer` |

Each package installs the variants of its program and links the best one the
processor supports into `/usr/bin`. `apt upgrade` installs new releases.

The repository holds the current release of each package. Earlier packages
are attached to their releases. Its contents are generated by the Distribute
Release workflow of each project.
